# 기획서 글꼴

제목과 큰 숫자는 **Jua(주아체)**, 설명과 표는 **Gowun Dodum(고운돋움체)**를 사용합니다.

[글꼴 묶음 다운로드](smartfarm_cute_fonts.zip) 후 압축을 풀고 두 TTF 파일을 설치하세요. PowerPoint가 열려 있었다면 다시 열면 됩니다. Windows에서는 묶음에 포함된 `install-fonts.ps1`로 현재 사용자에게 설치할 수도 있습니다.

글꼴은 **PPT 내부에 임베딩되어 있지 않습니다**. 다른 컴퓨터에서 같은 모양으로 편집하려면 두 글꼴을 설치해야 합니다. 설치하지 않으면 대체 글꼴 때문에 모양이나 줄바꿈이 달라질 수 있습니다.

두 글꼴은 SIL Open Font License 1.1로 배포됩니다. ZIP에는 수정하지 않은 원본 TTF, 라이선스 두 개, 설치 설명, 버전·해시가 담긴 manifest가 들어 있습니다.

- [Jua 공식 원본](https://github.com/google/fonts/tree/main/ofl/jua)
- [Gowun Dodum 공식 원본](https://github.com/google/fonts/tree/main/ofl/gowundodum)
