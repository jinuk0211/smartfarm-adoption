# 스마트팜 도입 판단 발표자료

[PPTX 다운로드](smartfarm_proposal.pptx) · [PDF 열람](smartfarm_proposal.pdf) · [명세서가 반영된 코드](../reports/dsz_spec_usage.md)

농가의 재배 계획을 출하량·총매출·비용 시나리오로 연결하는 발표자료입니다. **본편 16장과 근거 부록 12장, 총 28장**으로 구성했습니다.

- **글꼴·이미지:** Noto Sans KR, 설명용 생성 사진 9개, 실제 앱 화면 2개를 사용했습니다. 생성 사진은 실제 농장·제품·안심구역의 기록 사진이 아닙니다.
- **편집·노트:** PPTX의 표 12개와 차트 5개는 편집할 수 있습니다. DSZ 전체 79필드는 **18장 발표자 노트**에 보존했습니다.
- **PDF:** 슬라이드를 이미지로 변환한 열람용 파일입니다. 발표자 노트 확인과 텍스트·표·차트 수정에는 PPTX를 사용하세요.

## 자료와 검증 범위

DSZ 명세를 컬럼·타입·키 검사, 시설·경영조사의 작기 연결, 학습·예측·경제성 계산 코드에 반영했습니다. **실제 미개방 원자료는 0행**이며, **합성 40시설·80작기**로 실행 동작을 확인했습니다. 실제 원자료의 학습·성능 검증은 안심구역에서 진행해야 합니다.

명세서 기반 모델과 공개자료 모델의 입력은 서로 다릅니다.

| 구분 | 입력 |
| --- | --- |
| DSZ 명세 기반 · 7개 | 품목, 지역, 온실 유형, 규모 설명, 면적, 시작 연도, 시작 월 |
| 공개자료 모델 · 8개 | 품목, 품종, 시·도, 시·군·구, 시설 유형, 면적, 시작 연도, 시작 월 |

공개자료 실험 결과와 경제성 가정 시연도 구분합니다. 연소득 약 346.68만원과 6년 회수 예시는 과거 집계값과 가정으로 계산한 별도 시연입니다. 연소득은 가족노동 기회비용 차감 후, 회수기간은 차감 전 현금흐름 기준이며 개별 농가의 검증된 수익을 뜻하지 않습니다.
