예측한 출하량을 판로·등급별로 배분하며 합계는 100%입니다. 무상 출하처럼 대금이 발생하지 않는 출하분만 단가 0원으로 명시하세요.

단가는 농가 수취단가(원/kg)입니다. 이미 단가에서 뺀 판매수수료·운송비를 비용에 다시 넣지 마세요. 기간별 출하 배분도 직접 정하는 가정입니다.

현재 확인된 연결과 이번 계획의 차이

공개 API 출하·비용 자료에서 같은 시설·작기 키가 겹치는 것은 2작기이며, 딸기는 0작기입니다. 이 페이지는 그 빈 비용을 평균으로 채우지 않고, 위에서 지정한 대상 시설의 판매·비용·투자 근거를 받아 계산합니다.

경기도농업기술원 2023년 보고서 PDF 52–54쪽(인쇄 400–402쪽)의 평택 딸기 사례는 시설 1,600㎡와 조수입·경영비·소득이 같은 사례에 연결됩니다. 1,000㎡당 650만원 − 115만원 = 535만원으로 검산됩니다. 현재 출하량 모델과 같은 농가라는 연결은 없습니다.

해당 사례는 수량 단위·작기 기간이 불명확해 kg 예측 모델이나 연간 회수기간 검증에 넣지 않았습니다. 시범 사업비 2천만원도 전체 시설 투자비가 아닙니다. 이 참고 사례의 비용을 입력란에 자동 적용하지 않습니다.

출하량 모델의 검증 오차와 소득·회수기간의 정확도는 별개입니다. 위의 시설·기간 일치 검사는 입력 연결을 확인하며, 실제 소득 정확도나 설비의 생산성 향상을 입증하지 않습니다.
