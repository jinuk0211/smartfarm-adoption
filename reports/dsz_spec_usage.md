# 대회 명세서는 코드의 어디에 쓰였나요?

**2026-10-18 수정 기준입니다.** 명세의 컬럼·타입·키와 시설·경영조사 처리 코드를 구현했습니다. 실제 미개방 원자료는 로컬 0행이며 합성 40시설·80작기로 동작을 확인했습니다. 공개 농가자료의 성능을 DSZ 성능으로 제시하지 않습니다.

이전 이미지·PPT의 조사일 기반 연결 및 기간 미확정 상태의 학습 설명은 [현재 데이터 흐름](../DATA_FLOW.md)과 [기간 검사 수정](dsz_period_gate_repair_20261018.md)으로 대체합니다. 과거 그림은 [README의 보존자료](../README.md#이전-발표자료와-이미지)로 분류했습니다.

## 명세 반영 범위

| 자료 | 현재 역할 |
|---|---|
| DZ_002 시설 | 시설·작기 식별과 사전 입력 7개 구성 |
| DZ_004 경영조사 | 기간 근거가 확인된 출하량·총수입 목표 |
| DZ_001 환경·DZ_003 생육 | 컬럼·타입·키 검사와 목록 작성만 |
| DZ_005 기상·DZ_006 특보·DZ_007 태풍 | 컬럼·타입·키 검사와 목록 작성만 |
| DZ_008 이미지·DZ_009 종묘·DZ_010·011 축산 | 현재 DSZ 모델 범위에서 제외 |

스키마에 반영한 7종 79필드는 환경 16·시설 12·생육 16·경영조사 7·기상 10·특보 8·태풍 10개입니다. **79개를 모두 모델 입력으로 쓰지 않습니다.** 관측값의 현실적 범위·시설 외래키·측정 시간 정합성까지 검증했다는 뜻도 아닙니다.

## 사전 입력 7개와 목표 2개

| 명세 컬럼 | 모델 입력 |
|---|---|
| ITEM_NM | crop: 품목 |
| AREA_NM | region: 지역 |
| SACT_INTLCK_SPR_NM | greenhouse_type: 단동·연동 |
| HTHS_SCL_CN | greenhouse_size: 온실 규모 설명 |
| HTHS_SFC | area_m2: 면적 |
| FRMTM_BGNG_YMD의 연도 | planned_start_year |
| FRMTM_BGNG_YMD의 월 | planned_start_month |

시설ID는 연결·검증 그룹으로 사용합니다. 실제 종료일·조사일·환경·생육·기상 관측값·시설/작기ID는 사전 입력이 아닙니다.

목표는 ALL_SHPMNT_KGUNT_QTY → reported_shipment_kg(kg), ALL_INCM_AMT → reported_revenue_krw(원)입니다. 각각 확인된 적격 자료로 별도 학습하며 결측을 0으로 바꾸지 않습니다. **총수입은 매출이며 순이익이 아닙니다.**

## 조사일과 집계기간을 구분

시설ID가 같고 조사일이 작기 안에 있다는 사실은 감사 후보를 만드는 조건일 뿐입니다. 학습에는 정의 근거 문서·원본 해시·집계 정책·검토 기록과 **원행→시설·작기 매핑, 각 행의 집계 시작·종료일**을 요구합니다. 근거가 있으면 작기 종료 뒤 조사한 정산도 올바른 작기에 연결합니다.

- 단일 기록: 전체 작기 총량이라는 근거와 일치하는 집계기간.
- 증분 합산: 각 행이 겹침·공백 없이 전체 작기를 포함.
- 최신 누계: 작기 시작부터 누계이며 최신 행이 작기말 최종 누계.

정책 선택만으로 확인되지 않습니다. 근거 없는 후보는 감사용이고 학습·예측·경제성 연결에서 차단합니다. 일부만 확인됐으면 확인된 적격 행만 쓰고 전체 감사 후보와 사용·제외 내역을 보존합니다. 정책·근거·해시를 후속 결과에 전달합니다. ‘항상 미확정이어도 학습 가능’이라는 이전 설명은 더 이상 유효하지 않습니다.

## 예측에서 경제성까지

출하량 경로는 예측 kg와 대상 시설에 적용할 수취단가를, 총수입 경로는 예측 원 금액을 사용합니다. 두 경로를 더하거나 총수입에 면적·단가를 다시 곱하지 않습니다. 비용·투자 근거와 적용 기간을 별도로 확인하며 **연 1작기 동의만으로 미확정 목표 기간을 우회하지 못합니다.**

시설별 검증 점수로 모델을 선택하므로 독립적인 최종 평가·미래 성능·장비 효과를 입증하지 않습니다. 문서·해시 검사는 근거 기록의 일관성을 확인하며 기관 인증이나 실제 경제성 검증을 대신하지 않습니다. 명세 반영·합성 실행만으로 대회의 실제 미개방 데이터 활용 실적을 입증하지 않습니다.
