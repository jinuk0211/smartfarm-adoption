# 전 과정 구현과 산출물 확인

2026-10-10 기준. 원래 그림의 데이터 수집·연결, 모델 비교·예측, 비용 계산, 시나리오, 대시보드, 기획서 과정을 연구용 프로토타입으로 실행했다. 안심구역 원자료는 현장에서만 이용 가능하므로 사용자가 승인한 명세·합성 자료 기반 실행 경로를 유지한다. 실제 미개방 데이터의 정확도나 투자성과를 검증했다는 주장은 하지 않는다.

## 실제 실행에서 얻은 결론

딸기 수경 1,000㎡ 계획 예시는 2023·2024년 전국 조사 2행의 중앙값인 3,344.5kg을 수량 기준으로 사용한다. 개별 농가의 검증된 생산량 예측이 아니다. 공개 장비 가격에 설치·부가세·기타 시설비 가정을 더한 초기 투자비는 112,530,300원이다. 정부 온실 기준 단가를 장비 가격과 중복 합산하지 않았다.

기준 시나리오 연 매출 36,348,026원, 자가노동 차감 전 소득 15,565,061원, 자가노동 기회비용 차감 후 소득 3,466,801원이다. 10년·할인율4%·교체비0 가정에서 NPV는 52,565,864원이며 초기 투자 회수는 6년 말이다. 회수 계산의 현금흐름은 자가노동 기회비용 차감 전이다. 불리 조건에서는 10년 내 회수하지 못한다. 이 수치는 실제 농가 성과나 권장 투자금이 아니다.

KAMIS 2025년 고정 평가 106개월의 MAE는 선택 방법 1,249.16원/kg, 단순 같은 달 최근값 1,061.62원/kg으로 기준값이 더 좋았다. 2026년 전망은 2025년 말 기준의 과거 시점 전망이다. 이를 현재 예정연도의 검증된 전망으로 표시하지 않는다.

운영 중 초장 실험은 생육 원행2,529개 중 초장mm252개를 시설·방문187회로 집계한 뒤, 7일 간격40쌍·21시설을 비교했다. MAE는 초장 유지36.08mm, 생육 CatBoost32.61mm, 생육+환경 CatBoost34.79mm, 생육+환경 XGBoost34.59mm다. 환경을 추가한 개선은 확인하지 못했다. CO₂는 분석일자별 농도이며 하루 내 집계 방식은 미확정이다.

## 명시적으로 남겨 둔 데이터 제약

일사량·실제 외부기상·경보·태풍이 현재 딸기 큐레이션 원본에 없어, 이 실험에서 누적일사량·GDD·기상 예측 성능을 만들지 않았다. 원래 그림의 특징 예시는 확보된 실제 필드에 맞춰 내부 온도·습도·CO₂의 과거 요약으로 구현했다. 미개방 명세의 선택 테이블은 현장 파일 검사를 지원한다.

검증된 작기별 비용, 장비 도입 전후 이력, 현장 견적, 미래연도 외부검증은 추가 사업 검증에 필요하다. 부족한 자료를 실제로 확보한 것처럼 처리하지 않았다. 센터 제출·허용 결과 반출이나 실제 사업 집행을 대신 완료한 것은 아니다.

## 검증과 공개 범위

전체 로컬 테스트 224개와 하위검사63개 통과. 독립 Python 검토에서 가격의 시간 분리, 환경·생육의 미래 입력 차단과 시설 분리, 비용·현금흐름 산식, 결과의 해시 검증을 확인했다. 실제 브라우저에서 예시 입력·계산·가격·생육 화면을 실행하고 오류0건을 확인했다. 입력 변경 시 기존 결과를 현재 결과처럼 표시하지 않는다.

공개 소스 체크아웃의 기본 검사는 215통과·1건건너뜀·하위검사63통과다. 실제 자료가 필요한 앱 검사는 로컬 전체 검사에 포함하고 공개 체크아웃에서는 제외한다. 최종 PPT는 재수입·전체20장 렌더링과 개별 시각 검토를 마쳤고, 브라우저에서 받은 PPT의 SHA256이 전달본과 일치했다. 계산 결과 JSON 다운로드의 투자비·수량도 실제 예시와 일치했다. PowerPoint 네이티브 앱에서 직접 열어본 검증은 포함하지 않는다.

공개 저장소에는 코드·정의서·합성 예제·설비 등록가격·집계 결과·PPT·화면 캡처만 포함한다. 실제 농가 원행, 시설·날짜별 OOF, 인증정보·키, GPU 가중치는 포함하지 않는다. 특히 `inseason_oof_private.csv`는 로컬 감사 자료다.
