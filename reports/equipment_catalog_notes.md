# 설비 공개가격을 이용한 도입비 계산

확인일: **2026-10-10**. 스마트팜코리아의 업체 등록 장비 표준가격 3건을 정리했습니다. 실제 농가 계약금액·설치 완료 비용이 아니며, 최신 유효 견적을 의미하지 않습니다.

출처는 [스마트팜코리아 장비 소개](https://www.smartfarmkorea.net/company/equipmentInfo.do)입니다. 상세 페이지는 `https://www.smartfarmkorea.net/company/selectEquipment.do?menuId=`에 `eqpmnSeq`를 POST하는 방식입니다. 수집 근거는 `reports/equipment_source_check_2026-10-10.json`이며 가격표만 보존합니다.

| 6337 | 옹달샘300 양액 공급 구성 | 3,270,000원 | 일사센서 400,000원 |

## 계산 원칙

- **공개 묶음 합계 × 묶음 수량**을 계산합니다. 묶음에 이미 들어 있는 구성품은 다시 더하지 않습니다.
- 6337의 액비전자밸브에는 수량 3, 표시가격 120,000원이 나옵니다. 단가인지 행 합계인지 불명확하므로 이를 3배 하지 않고 공개된 묶음 합계 3,270,000원을 사용합니다.
- 옵션은 선택했을 때만 포함합니다. 옵션별 가격은 묶음 하나당 선택 수량 1개 기준이며, 묶음 수량이 2이면 선택 옵션도 2개로 계산합니다.
- 부가세·설치비 포함 여부는 미확인입니다. **추가 설치비**와 **추가 부가세 금액**을 각각 명시하지 않으면 장비 소계만 반환하고 `initial_capex_krw`는 `None`입니다.
- 추가금액 0원은 사용자가 추가 부담이 없다고 가정한 것입니다. 견적 검증이 완료됐다는 뜻이 아닙니다. 부가세율이나 포함 여부를 자동 가정하지 않습니다.
- 총액은 선택 장비와 사용자가 입력한 부대비용 범위에 한정됩니다. 신축 시 온실·토목·전기·수도 등 빠진 비용을 별도로 포함해야 합니다.
- 면적에 따라 장비 수량을 자동 추천하지 않습니다. 양액기 두 종류는 대안 구성으로 비교하는 것이 기본이며, 조합의 기술적 호환성·용량은 확인되지 않았습니다.
- 이 자료로 수확 증가율, 유지보수비, 수명, 감가상각기간을 학습하거나 추정하지 않습니다. 해당 경제성 가정은 별도 입력입니다.

## 사용 예시

```python
from src.equipment_costs import estimate_equipment_cost, load_catalog

catalog = load_catalog()
result = estimate_equipment_cost(
    catalog,
    [{"equipment_id": "6337", "quantity": 1,
      "option_ids": ["6337-option-1"]}],
    installation_krw=1_000_000,  # 사용자가 입력한 추가 설치비
    additional_vat_krw=0,      # 추가 부가세가 없다는 사용자의 명시적 가정
)
# equipment_subtotal_krw = 3,670,000
# initial_capex_krw = 4,670,000 (계획용 가정)
# is_verified_quote = False
```

`initial_capex_krw`를 경제성 계산에 연결할 수 있지만, 리모델링에서는 기존 영농 대비 추가 투자비인지 확인해야 합니다. 신축에서는 이 값만으로 전체 농장 초기비용을 대표하지 않도록 온실 등 누락 비용을 포함합니다. 기존 대비 증분현금흐름 없이 장비 투자 회수기간을 장비의 실증 효과로 해석해서는 안 됩니다.
