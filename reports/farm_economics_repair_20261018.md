# 시설별 출하·경제성 연결 보완

2026-10-18. **기존 설명에는 같은 농가의 생산·판매·전체 비용·투자비를 연결한 것처럼 표현한 오류가 있었습니다.** 실제로는 공개 농가자료 예측값에 RDA 품목·지역 평균과 가격·설치비 가정을 결합했습니다. 외부 평균은 대상 시설의 실측값이 아닙니다.

## 수정한 흐름

1. 대상 시설·면적·품종·지역·시설유형·작기·연간 운영기간을 정합니다.
2. 기존 딸기 출하량 모델로 해당 계획의 출하량을 추정합니다.
3. 같은 대상에 적용할 판매기간·판로·등급별 배분율·수취단가를 입력합니다. 배분 합계는 100%입니다.
4. 현금 운영비 7항목·감가상각·가족노동의 총 9항목을 입력합니다. 현금비용은 연간 총액 또는 출하 1kg당 비용으로 구분합니다.
5. 같은 대상의 투자 견적·포함/제외 범위·교체 계획을 연결합니다.
6. 신규 시설은 전체 현금흐름, 개량은 같은 시설의 기존 유지안 대비 추가 현금흐름으로 소득·회수기간을 계산합니다.

Streamlit의 **도입 전 계산 → 내 시설 계획으로 계산**과 정적 웹의 **facility-plan.html**이 수정 경로입니다. 외부 평균은 자동 입력하지 않고 참고 예시로 구분합니다.

모든 판매·비용·투자·유지안 행의 대상 범위를 검사하며 조건이 바뀌면 근거를 다시 확인합니다. 기록·견적·예산·참고값을 구분하고 미입력 비용을 0으로 바꾸지 않습니다. 수량 변화는 kg당 비용에도 반영합니다. 면적 중복 곱셈을 막고 감가상각·가족노동 기회비용·현금지출을 구분합니다. 최초 회수시점과 기간 말 잔액을 함께 표시하며 입력 변경 시 이전 결과를 현재 결과로 제시하지 않습니다.

이는 적용 범위 검사이며 입력 문서의 진위·장비 효과·실제 수익 인증이 아닙니다. 학습 농가와 새 계획 대상이 같다는 뜻도 아닙니다.

## 실제 자료와 검증 한계

[연결 감사](farm_economics_evidence.md)의 API 출하 2,823행·161작기와 비용 99행·7작기는 **2작기만 겹칩니다.** 토마토·방울토마토 각 1작기이며 비용은 각각 1행뿐입니다. **딸기 교집합 0작기, 전체 비용 확인 작기 0작기**입니다.

공개 보고서의 농가 사례는 시설·보고 매출·경영비·소득의 산술을 검산했지만 작기 기간·수량 단위·전체 투자비가 부족합니다. [추가 공개자료 확인](farm_economics_public_access_20261018.md)에서도 요구한 딸기 결합 원자료를 새로 확보하지 못했습니다.

수정 당시 원자료가 있는 **로컬 환경**에서 대상 Python 104개·웹 29개 검사를 통과했습니다. 현재 **공개 소스 환경**의 검사는 [README 검증](../README.md#검증과-공개-범위)에 별도로 기록했습니다. 두 집계를 합치지 않습니다. 브라우저 화면 배치의 육안 검증은 완료하지 못했습니다.
