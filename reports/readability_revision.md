# 화면과 기획서의 가독성 개선

이 문서는 첫 가독성 개편 당시의 기록입니다. 이후 기획서는 주아체·고운돋움체와 새 일러스트 10장을 사용한 버전으로 교체했습니다. 최신 파일·글꼴은 [발표자료 안내](../presentation/README.md)를 따릅니다. 아래 PPT 해시는 이전 버전의 기록입니다.

2026-10-10. 기능 중심으로 나열했던 화면과 발표자료를 농가와 심사위원이 읽는 순서로 재구성했다. 예측 모델, 경제성 산식, 원자료와 계산 가정은 유지했다.

## 대시보드

- 첫 화면은 서비스의 질문과 예시 시작 버튼, 초기 투자비·자가노동 반영 소득·투자 회수 시점을 먼저 보여준다.
- 계획 입력을 재배 계획, 투자 계획, 조건 비교로 묶었다. 추가 가정과 원자료·검증 근거는 펼쳐볼 수 있다.
- 결과에서는 큰 숫자와 현금흐름 차트를 먼저 제시한다. 회계상 소득과 투자 회수에 사용하는 현금흐름의 차이를 보존했다.
- 가격·생육 화면은 실험에서 확인한 결론을 먼저 설명하고, 세부 모델 점수와 데이터 수량은 상세 영역으로 옮겼다.
- 영문 원컬럼·JSON·실행 명령은 기본 읽기 흐름에서 제외하고 필요한 다운로드와 상세 근거에 남겼다.

## 발표자료

핵심 설명은 본편 14장으로, 출처·데이터 정의·전체 실험 결과와 가정은 부록 14장으로 나눴다. 본편에는 편집 가능한 큰 수치와 차트를 배치하고, 긴 표는 부록에 두었다. 중요한 한계는 본편에서도 확인할 수 있다.

예시의 연 소득 약 347만원은 자가노동 기회비용을 반영한 값이다. 투자 회수 6년은 자가노동 기회비용 차감 전 현금흐름을 기준으로 한다. 둘을 같은 기준의 수익으로 표현하지 않았다. 장비 등록 가격이 생산성 향상 효과를 증명하지 않으며, 실제 안심구역 원자료의 성능은 현장 평가가 필요하다.

## 확인한 범위

- 계산·입력 변경·설비비·가격과 기상 연결·출처 검증을 확인하는 기존 UI 검사 12개 통과. Python 독립 검토와 Ruff도 통과했다.
- 실제 브라우저에서 예시 불러오기, 계산, 가격·생육 전환을 확인했다. 화면 오류 0건이며 기본 화면에 실행 코드가 표시되지 않는다. 390px 폭에서도 문서의 가로 넘침이 없었다.
- 최종 28장 PPT를 다시 읽어 전부 렌더링하고 개별 검토했다. 표 9개, 차트 3개와 차트용 통합문서 3개를 편집 가능한 상태로 보존했다. 파일 구조·레이아웃·폰트 검사에서 오류와 경고가 없었다. PowerPoint 네이티브 앱 실행은 검증 범위에 포함하지 않았다.
- 실제 화면에서 내려받은 PPT와 전달본의 SHA256이 `e1ddb80ee978bb477fd513b2c7dcdc981070bdc673a186fdbbc2aabd96dbefda`로 일치했다. 계산 결과 다운로드도 예시 투자비 112,530,300원과 수량 3,344.5kg을 유지했다.
